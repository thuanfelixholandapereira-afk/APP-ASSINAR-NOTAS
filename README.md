# Assinador PDF — Android

Aplicativo Android para assinar PDFs no celular com assinatura fixa embutida.

Recursos:
- assinatura fixa já incorporada;
- padrão de 8 cm da borda inferior;
- assinatura somente na primeira página;
- múltiplos PDFs;
- ZIP para lote;
- ajustes de posição e tamanho;
- seletor de PDFs do Android;
- saída em Downloads/Assinador PDF.

O build automático do APK é feito por GitHub Actions.
